# OpenNetGuide · 开放上网指南

整理与分享日常上网相关的实用教程、工具说明、经验和故障排查记录。欢迎通过 Pull Request 补充和修订内容。

## 内容约定

- 本仓库是公开的，提交到这里的内容任何人都可以阅读。
- 请勿提交密码、访问令牌、个人信息或其他不应公开的材料。
- GitHub 不能在同一个仓库中按目录设置读者权限。需要保密的内容应放在单独的私有仓库中，并只邀请获准人员。
- 引用外部资料时请附上来源链接；提交内容应为原创，或符合原资料的转载许可。
- 项目尚未指定内容许可协议。许可确定前，请勿将他人的受版权保护材料复制进来。

## 如何参与

请先阅读 [CONTRIBUTING.md](CONTRIBUTING.md)，再通过 Pull Request 提交修改。主分支应在 GitHub 仓库设置中启用保护规则，要求通过 Pull Request 合并，并禁止强制推送和删除主分支。
