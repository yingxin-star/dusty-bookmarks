# 收藏夹吃灰

我说收藏很重要有没有懂的：把日常上网和数字生活经验整理成可搜索、可复用的中文内容。项目分享 ChatGPT 与 CC Switch 等软件工具、网络访问、实用网站、Steam 和游戏购买经验。每篇内容独立保存为一个 Markdown 文件，按主题放入对应中文文件夹，并在分区的 `目录.md` 中添加入口。

## 内容分区

- [ChatGPT 与 AI](内容/ChatGPT与AI/目录.md)：ChatGPT 注册、下载与使用，AI 工具和相关服务。
- [软件工具](内容/软件工具/目录.md)：CC Switch、客户端及其他软件的安装和使用。
- [网络访问](内容/网络访问/目录.md)：网络访问工具、连接经验和相关风险记录。
- [实用网站](内容/实用网站/目录.md)：工具网站、资源网站及价格查询服务。
- [游戏与购买](内容/游戏购买/目录.md)：Steam 使用知识、游戏购买流程、地区价格和数字商品经验。

## 内容记录方式

- 使用直白、可搜索的中文文件名和标题，例如“ChatGPT 注册与下载”。
- 标明内容状态：亲自测试、公开资料整理、他人反馈或尚未验证。
- 对会变化的步骤、价格和服务信息注明来源与最近核对日期。
- 第三方服务和个人体验不代表项目背书；使用或购买前请自行核实当前信息。
- 优先链接官方注册、下载和帮助页面；不要发布账号密码、访问令牌、个人信息或私下配置。
- 新建文章时可复制 [单篇内容模板](模板/单篇内容模板.md)。
